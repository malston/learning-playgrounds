Five Kinds of Forgetting

Each type of amnesia is addressed by a specific layer.

"Who are you again?"

Re-explaining preferences every session: documentation style, naming conventions, technical depth.

Auto-Memory (user type)

"Didn't I tell you not to do that?"

Re-correcting the same mistakes: em dashes, mocking databases, code style drift.

Auto-Memory (feedback type)

"What were we working on?"

Multi-session projects losing coherence after compaction. Agent declares victory prematurely.

Beads (bd ready)

"What should I do next?"

Complex work with dependencies gets jumbled. Agent finishes A but doesn't realize B is unblocked.

Beads (bd close --suggest-next)

"Didn't we solve this before?"

Encountering a problem debugged weeks ago with no way to search for or recover the solution.

Two Search Systems, Different Slices

Claude-mem and episodic memory both search past sessions -- but they record fundamentally different things.

Claude-Mem

The lab notebook -- what you did and what happened
  • Records via PostToolUse hook -- fires after every tool call
  • Captures: file reads, edits, test runs, command outputs
  • Session summaries via Stop hook
  • Does not capture: reasoning, verbal instructions, design debates
  • 3-step retrieval: search → timeline → get_observations

Episodic Memory

The meeting transcript -- what you discussed and why
  • Records via SessionStart hook -- background sync of transcripts
  • Captures: user instructions, agent reasoning, design discussions
  • Indexes full conversation text for semantic + text search
  • Does not capture: tool outputs, intermediate results lost to compaction
  • 2-step retrieval: search → read
